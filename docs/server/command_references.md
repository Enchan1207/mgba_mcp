# mGBAサーバ コマンドリファレンス

`mgba_server --rom <ROM_PATH> --socket <SOCKET_PATH>` で起動し、Unix domain socket で要求を受け付けます。接続後、最初の行に `HELLO CONTROL` または `HELLO VIEW` を送ってください。`CONTROL` は同時に一接続、`VIEW` は複数接続できます。

要求は改行を含めて 32 バイト以内の ASCII 行です。コマンド名とボタン名は大文字・小文字を区別しません。各要求には、結果 `S` または `E` の 1 バイト、本文長のリトルエンディアン `uint32_t`、本文、改行 1 バイトで応答します。空行・不正な引数には `BAD_REQUEST` を返します。役割に許されないコマンドには `FORBIDDEN` を返します。

## WAIT_FRAME

```text
WAIT_FRAME <タイムアウト（ミリ秒）>
```

`VIEW` 接続で、画面更新またはリセットを最大 1～60000 ミリ秒待ちます。画像がない場合は `NO_FRAME`、時間切れでは `TIMEOUT` を返します。画像本文は 8 バイトの経過フレーム数、幅と高さ各 1 バイト、RGBX8888 画素列です。

## STEP

```text
STEP <フレーム数>
```

### 概要

指定したフレーム数だけエミュレーションを進めます。

### 詳細

- フレーム数には `1` から `18000` までの整数を指定します。
- 実行したフレーム数は経過フレーム数に加算され、最新の画面画像を取得できる状態になります。

## PRESS

```text
PRESS <ボタン>
```

### 概要

指定したボタンを押下状態にします。

### 詳細

- ボタンは `A`, `B`, `SELECT`, `START`, `RIGHT`, `LEFT`, `UP`, `DOWN` のいずれかを指定します。
- 押下状態はフレームを進めても維持されます。

## RELEASE

```text
RELEASE <ボタン|ALL>
```

### 概要

指定したボタンの押下状態を解除します。

### 詳細

- ボタンは `A`, `B`, `SELECT`, `START`, `RIGHT`, `LEFT`, `UP`, `DOWN` のいずれかを指定します。
- `ALL` を指定すると、すべてのボタンの押下状態を解除します。

## RESET

```text
RESET
```

### 概要

エミュレーションをリセットします。

### 詳細

- 押下中のボタンと経過フレーム数を初期化します。

## STATUS

```text
STATUS
```

### 概要

現在の動作状態を取得します。

### 詳細

- 状態には押下中のボタン、経過フレーム数、画面画像の有無が含まれます。

## CAPTURE

```text
CAPTURE
```

### 概要

最新フレームの画面画像を取得します。`CONTROL` と `VIEW` の両方で使用できます。画像本文は `WAIT_FRAME` と同じ形式です。

### 詳細

- 画面サイズは `160 × 144` ピクセルです。
- **NOTE**: 最初の `STEP` の前および `RESET` の直後は画像を取得できません。

## QUIT

```text
QUIT
```

### 概要

`CONTROL` 接続からエミュレータとサーバの終了を指示します。
