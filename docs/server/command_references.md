# mGBAサーバ コマンドリファレンス

コマンド名とボタン名は大文字・小文字を区別しません。前後の空白やタブは許容され、空行は無視されます。各コマンドは、以下に示す引数だけを受け付けます。

## STEP

```text
STEP <フレーム数>
```

### 概要

指定したフレーム数だけエミュレーションを進めます。

### 詳細

- フレーム数には `1` から `18000` までの整数を指定します。
- 実行したフレーム数は経過フレーム数に加算され、最新の画面画像を取得できる状態になります。

## PRESS

```text
PRESS <ボタン>
```

### 概要

指定したボタンを押下状態にします。

### 詳細

- ボタンは `A`, `B`, `SELECT`, `START`, `RIGHT`, `LEFT`, `UP`, `DOWN` のいずれかを指定します。
- 押下状態はフレームを進めても維持されます。

## RELEASE

```text
RELEASE <ボタン|ALL>
```

### 概要

指定したボタンの押下状態を解除します。

### 詳細

- ボタンは `A`, `B`, `SELECT`, `START`, `RIGHT`, `LEFT`, `UP`, `DOWN` のいずれかを指定します。
- `ALL` を指定すると、すべてのボタンの押下状態を解除します。

## RESET

```text
RESET
```

### 概要

エミュレーションをリセットします。

### 詳細

- 押下中のボタンと経過フレーム数を初期化します。

## STATUS

```text
STATUS
```

### 概要

現在の動作状態を取得します。

### 詳細

- 状態には押下中のボタン、経過フレーム数、画面画像の有無が含まれます。

## CAPTURE

```text
CAPTURE
```

### 概要

最新フレームの画面画像を取得します。

### 詳細

- 画面サイズは `160 × 144` ピクセルです。
- **NOTE**: 最初の `STEP` の前および `RESET` の直後は画像を取得できません。

## QUIT

```text
QUIT
```

### 概要

エミュレータとサーバの終了を指示します。
