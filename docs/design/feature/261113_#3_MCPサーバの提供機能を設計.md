# MCPサーバで提供する機能の設計

[issue #11「MCPサーバで提供する機能を決める」](https://github.com/Enchan1207/mgba_mcp/issues/11)で提供するMCPツールを定義する。

## 公開ツール

### `press_button`

- 入力
  - `button`: `A`、`B`、`SELECT`、`START`、`RIGHT`、`LEFT`、`UP`、`DOWN`のいずれか。
  - `frames`: ボタンを押すフレーム数。省略時は10。
- 動作
  - 指定ボタンを`frames`フレーム押す。全ボタンを解放し、同じ`frames`フレーム進める。

### `walk_for`

- 入力
  - `direction`: `UP`、`DOWN`、`LEFT`、`RIGHT`のいずれか。
  - `frames`: 方向キーを押すフレーム数。
- 動作
  - 指定方向を`frames`フレーム押す。全ボタンを解放し、設定されたフレーム数だけ進める。
  - 実際の移動距離は保証しない。

### `wait`

- 入力
  - `frames`: 無入力で進めるフレーム数。
- 動作
  - 全ボタンを解放してから、無入力で`frames`フレーム進める。

### `get_screen`

- 入力
  - なし。
- 動作
  - 現在の公開画面をPNG画像で返す。
  - 画面がない場合は全ボタンを解放し、1フレーム進めてから取得する。

## 入力と結果の共通仕様

`walk_for`の解放後に進めるフレーム数はMCPサーバの設定値とし、初期値を10とする。`press_button`では、押下中と解放後に同じ`frames`を使う。フレーム数は`mgba_server`の`STEP`と`TYPE`の上限に合わせて1～18000とする。

操作ツールは終了時に全ボタンを解放する。`press_button`は`RELEASE ALL`、`TYPE <button> <frames>`の順で実行する。`walk_for`は`RELEASE ALL`、`PRESS`、`STEP`、`RELEASE ALL`、`STEP`の順で実行する。途中で失敗した場合もボタンの解放を試みる。

操作ツールは`framesAdvanced`と`totalFrames`を返す。前者は呼び出しで進んだフレーム数、後者は操作後の`STATUS`から取得した累積フレーム数とする。操作結果に画像は含めない。

`get_screen`で画面がまだない場合、取得のために1フレーム進める。その結果には`framesAdvanced: 1`と画像の経過フレーム数を含める。既存の画面を取得した場合、`framesAdvanced`は0とする。

サーバコマンドの形式と制限は[コマンドリファレンス](../../server/command_references.md)に従う。
