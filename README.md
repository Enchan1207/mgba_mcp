# AIエージェントにmGBAを操作させる

## Overview

mGBAのソケットサーバとMCPサーバを構成し、AIエージェントがゲームをプレイできるようにする

## ディレクトリ構成

- `mgba_server/`: mGBAを使うソケットサーバのCMakeプロジェクト
- `mgba_mcp/`: MCPサーバ用ディレクトリ（実装予定）
